# trade

Сервис отслеживает пары к USDT на Binance и присылает уведомления в Telegram о резких движениях за последние 15 минут. Интервал замеров фиксирован — каждые 5 минут.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Конфигурация
Переменные окружения:
- `TELEGRAM_TOKEN` — токен Telegram-бота (обязателен для работы бота).
- `TELEGRAM_CHAT_ID` — необязательный ID чата/канала для уведомлений по умолчанию. При первом `/start` бот автоматически добавит ваш чат.
- `DEFAULT_THRESHOLD` — порог для всех пар, кроме настроенных отдельно (проценты, по умолчанию `5`).
- `THRESHOLD_BTC`, `THRESHOLD_ETH`, `THRESHOLD_SOL`, `THRESHOLD_XRP`, `THRESHOLD_SUI` — пороги для соответствующих пар `*_USDT` (проценты, необязательные).

Храните токен и chat_id в переменных окружения или файле `.env`, который не попадает в репозиторий (см. `.env.example`).

Пример файла `.env`:

```env
TELEGRAM_TOKEN=your-telegram-token
TELEGRAM_CHAT_ID=your-chat-id
DEFAULT_THRESHOLD=5
THRESHOLD_BTC=4
THRESHOLD_ETH=4
THRESHOLD_SOL=6
THRESHOLD_XRP=5
THRESHOLD_SUI=7
```

## Запуск
```bash
python monitor.py
```

### Управление из Telegram
1. Отправьте `/start` боту — чат сохранится для уведомлений.
2. Используйте кнопки «По умолчанию» и отдельные пары в меню, чтобы задать порог изменения в процентах.
3. Команда `/settings` повторно покажет меню, `/thresholds` — текущие значения.

### Что отслеживает сервис
- Каждые 5 минут запрашивает цены всех пар `*USDT` на Binance.
- Сравнивает текущую цену с ценой 15 минут назад.
- Уведомляет, если модуль изменения превышает установленный порог для конкретной пары или общий порог для остальных пар. Повторные уведомления по одной паре приходят не чаще, чем раз в 15 минут.
